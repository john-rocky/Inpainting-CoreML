# Inpainting-CoreML

**Image inpainting models converted to Core ML — including LaMa, MAT, and Stable Diffusion inpaint. iOS sample apps included.**

By [Daisuke Majima](https://john-rocky.github.io). Maintainer of [CoreML-Models](https://github.com/john-rocky/CoreML-Models) (1,749★). Powers [AIPainter](https://apps.apple.com/us/developer/daisuke-majima/id1350309854) and [Mask2Face](https://apps.apple.com/us/developer/daisuke-majima/id1350309854) on the App Store.

1, Download or Clone this project and open in xcode.

2, Please change the "Team" field of xcode Signing and Capabilities to your account.

3, Run.
